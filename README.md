# 読書手帖（book-app）

個人の読書アプリ。iPhoneのSafariから使う独立Webアプリ（PWA）。確認版：**v0.15.5 / 2026-10-15**（サイトは公開中。手元の変更の公開反映にはpushが必要）。Claude Code と Codex が交代で開発している（引き継ぎは共通フォルダの notes）。

## 画面（下のナビ：本棚・著書・検索・記録）

| 画面 | 内容 |
|---|---|
| 本棚 | 表紙のグリッドと一覧を切替。上部の切り替えで「著者順（五十音）・登録順・刊行順・ジャンル・シリーズ」。シリーズ（v0.9・`js/series.js`）は書名の終わりの巻数でまとめ、国会図書館で他の巻と発売予定を補い、読了数・次に読む巻・最新刊を出す。ジャンルはガラス面のボタンで絞り込み（スマホは「すべて」を1段目に全幅、370px以下は2列）。本棚内の検索、スクロールに合わせて24冊ずつ自動表示し、本は画面に入ると下から浮かぶように現れる（同時に入った本は70msずつ時間差・動きを減らす設定では即表示）。登録日と刊行日は昇順・降順を切替。読書状態のタブは置かない（読了は記録で見る）。 |
| 本の詳細 | 読書状態、読了日、評価、メモ・感想、ジャンル、書誌編集（著者の読みを含む）、買う/借りるリンク。 |
| 著書（v0.9。旧「著者」。URL は #author のまま） | 本棚の著者を自動でフォロー（auto:true）。上の切り替えで「新刊」（これから出る本を発売の早い順・月ごと、最後に発売済み）「持っていない本」（本棚に多い著者から4人ずつ、本棚にない著作）「カレンダー」（ひと月／1週間。日付をタップで表紙と内容紹介）。新刊の確認は起動時に8人ずつ・同じ著者は12時間ごと、NEWと件数バッジ。点字・音声データ（サピエ図書館）のISBNのない記録は新刊にしない。著者の名前で探すのは検索タブ。著者名をタップすると著者のページ（全作品）。 |
| 本の情報（v0.8） | 新着・発売予定、おすすめ、検索結果、著者の作品の本をタップすると「著者→刊行日→あらすじ」を表示（`js/book-details.js`）。NDL（SRU）と openBD を同時に照会し、NDLが応答しないときは4→6→8秒で再試行。叢書の注記はあらすじにしない。手元の版が新しいときは「最初の刊行は○年」を添える。画面の近くで先読みし、保存済みのあらすじは詳細を開いたときに表示。読込や再試行の文言は出さない。初めて調べる本は、通信が完了してから内容が追加される。結果は24時間この端末に保存。本棚にあれば「本棚の記録を開く」、なければ「本棚に登録」。 |
| 検索 | 検索する前は「あなたへのおすすめ」（本棚の傾向または初回に選んだ好きなジャンルから、検索タブを訪れるたび入替・理由付き・「表示しない」）。上部のバーコード読取と、書名・著者・ISBNの統合入力欄で国立国会図書館を検索し「＋登録」で本棚へ（棚の種類は選ばない。読了などは本の詳細で）。バーコード連続読み取り、見つからない本の手入力登録。右上の「本を追加」もここを開く。検索欄を空にするとおすすめに戻る。 |
| 読書の記録 | いちばん上に「読書図鑑」の入口（v0.15.2）。何をいつ読み終えたかを月ごとに表示。年は 1 行の棒グラフ（年ごとの冊数。'25・7冊の表記）で絞り込み、同じ棒か「すべて」で全部に戻る（v0.15.2〜）。本の詳細の表紙に触れると大きく広がる（v0.15.3）。JSONバックアップと復元。 |

見た目：グレーとチャコールが基調（差し色もチャコール。深いグリーンは v0.5 で廃止）。文字は Noto Sans JP（取れなければ端末のゴシック体）。ロゴは本としおりのモノクロマーク（icons/mark.svg）。下のナビはリキッドグラス風。スマホ標準のプルダウンは使わず、画面内のボタンで選ぶ。

おすすめの仕組み（`js/recommend.js`）：本ごとの重み（読了＋評価が高いほど強く、読みたい本は気になり度で）から、よく出てくる著者とジャンルを出す。①よく読む著者4人（上位2人固定＋3〜12位から日替わり2人）の、まだ本棚にない作品 ②好きなジャンル順に、まだ本棚にいない代表著者（genres.js）3人の作品。著者ごとに2〜3冊（再訪時に作品を入替）、著者を交互に最大20冊。漫画・アンソロジー・本棚の本（版違い・同じ著者で書名が5文字以上重なる別訳/別題を含む）・「表示しない」にした本は除く。国会図書館へは著者1人1回、結果は7日間保存。検索を始めると集めるのを止める（検索を待たせない）。

ユーザー希望で外したもの：読書日数・連続日数・カレンダー・年間目標（v0.3）、ジャンル探索画面（v0.6 で検索タブに置き換え。旧 `#genre` は検索へ移動）、登録時・バーコード読み取り時の「入れる棚」の選択（v0.7。登録はすべて本棚へ）。旧バックアップとの互換のため保存項目は残している。

## 手元で動かす

```powershell
python -X utf8 _work/devserver.py 8765
```

このPCで http://localhost:8765 を開く（Claude Code はデスクトップ `.claude\launch.json` の `book-app`）。

## iPhoneで使う

1. 公開URL：https://hedficr-cyber.github.io/dokusho-techo/ （GitHub Pages・2026-10-13 公開。リポジトリ https://github.com/Hedficr-cyber/dokusho-techo ）
2. iPhoneのSafariで開き、「共有」→「ホーム画面に追加」。
3. 「検索」→「バーコードで読み取る」でカメラを許可（https でないとカメラは動かない）。許可できない場合はISBNを手入力。
4. 初回は好きなジャンルを複数選ぶと、おすすめが表示されます。本棚は空から始まり、自分が登録した本だけが並びます。新刊は本棚の著者を自動で確かめます。

## 保存と公開

- 本棚データは端末のブラウザのlocalStorageに保存。v0.10 から「記録」→「同期設定」（普段は折り畳み）で、本人の GitHub の非公開リポジトリ（既定 dokusho-techo-data）に**端末で暗号化して**保存し、端末の間でそろえられる（`js/sync.js`。仕組みは CHANGELOG の 0.10.0）。同期を使わない場合は「データのバックアップ」で JSON を書き出して移す。
- 同期の準備は本人が行う：非公開リポジトリの作成と、そのリポジトリだけの fine-grained token（Contents: Read and write）の作成・入力。AI は鍵（トークン）や合言葉を入力・保管しない。
- 新刊のお知らせはアプリを開いたとき（12時間ごと）に確認。ロック画面へのプッシュ通知は未実装。
- 公開は `main` ブランチをそのまま GitHub Pages で配信（`.nojekyll` あり）。現行版は個人の初期本棚を配布せず、初めて開くブラウザは空の本棚から始まる。過去のGit履歴の初期リストは残っている。新たな登録・読了・感想は各端末の中に保存され、設定済みの同期を除いて公開されない。別のURLやブラウザの本棚は自動では共有されない。
- `_work` の検証画像や中間ファイル、元の写真、`AGENTS.md` は公開しない（.gitignore で除外）。
- 更新の手順：変更をコミット → `git push`（認証は Git Credential Manager。Claude Code のシェルからは認証画面を出せないので、ターミナルパネルで実行）。

## セキュリティ

- コンテンツセキュリティポリシー（index.html の meta）：スクリプトは自サイトとバーコード部品（版・ファイル固定）だけ、通信は国立国会図書館と openBD（v0.8 の本の情報。本人がISBN等の送信を許可済み）と、同期をオンにしたときの api.github.com（暗号化した本棚の保存。本人が方式を選択）だけ、画像は表紙の配信元だけ。埋め込み・プラグイン・外部へのフォーム送信は禁止。配信元を足すときはここも直す。
- バーコード部品は改ざん検知（SRI）つきで読み込む。外部サイトへリファラを送らない。
- 画面に出す文字はすべてエスケープ。国会図書館へのリンクは `https://ndlsearch.ndl.go.jp/` で始まるものだけ。ISBN は数字と X だけ残す。
- GitHub Pages は HTTPS 強制（HSTS あり）。GitHub アカウントはパスキー設定済み。
- 確認：`_work/regression.cjs`（手元）と `_work/live_check.cjs`（公開サイト：外部スクリプトの差し込みが止まるか等）。2026-10-13 どちらも通過。

## ソースと検証

- `index.html` / `css/app.css`：骨組みとライト/ダークのデザイン。
- `js/app.js`：画面・操作。`js/store.js`：保存と旧バックアップ互換。`js/shelf.js`：本棚の並べ方。`js/recommend.js`：検索前のおすすめ。`js/authors.js`：著者の読み（五十音順用）。
- `js/covers.js`：同じ作品/同じ巻の旧版候補を照合。著者の近刊は保存済みのデータにも表紙を補充し、旧版の表紙と未取得を明示。本棚への登録後も候補を保持。
- `js/ndl.js`：国立国会図書館サーチ API（1件ずつ・429/無応答の再試行・7日キャッシュ）。`js/scan.js`：BarcodeDetector/ZXing。`js/genres.js`：ジャンル定義（本棚の絞り込みと本の詳細で使用）。
- `data/seed.json`：互換用の空データ（起動時に取り込まない）。`sw.js`（キャッシュ dokusho-techo-v18）/ `manifest.webmanifest` / `icons`：PWA。
- `_work/regression.cjs`：登録、ISBN、検索タブ、フォロー、復元、旧データ互換、320〜414px。`--live` で実APIとZXingも確認（Node.js と Playwright。Codex ランタイムの node_modules を NODE_PATH に指定すれば Claude 側でも実行できる）。2026-10-13 v0.7.2 で 14 項目すべて通過（おすすめ・初期リストの ISBN 修正・CSP の確認を含む）。
- `_work/release-cover-qa.cjs`：白い仮表紙、ISBN-10、同作品/同じ巻、候補の取得失敗と次候補、既存新刊の補充、既読/確認時刻保持、登録後の表紙、4画面幅/ダーク。`--live`で実NDLと画像配信元を確認。
- `_work/v080-qa.cjs`（Codex）/ `_work/v080-claude-qa.cjs`（Claude）：v0.8 の本の情報・ジャンル配置・スクロール出現・点字版の除外・NDL無応答時の再試行。
- `_work/liquid-genre-qa.cjs`：v0.4 のジャンル画面向けで、検索タブへの置き換え後は対象外（参考として残置）。
- `_work/ui-qa.cjs` / `pwa-smoke.cjs`：Codex 作成の表示・オフライン確認。

本アプリの開発ではユーザー指示によりナギ自動再開を停止。利用制限時は Claude/Codex を交互に使い、**再開時はまず共通引き継ぎフォルダで相手の進捗を確認してから**作業する。

「記録」画面の「バージョン履歴」で、日付と変更内容を確認できます。共通定義は`js/versions.js`、GitHubで読む変更記録は`CHANGELOG.md`です。コードはコミットと`v0.7.4`のようなタグで保存し、次回も履歴を書き足します。

2026-10-14 v0.7.4確認：既存の回帰13項目、昇降順・213冊までの自動追加・スマホ配置・バージョン履歴・不正入力とCSP、実書誌と実表紙（ISBN空欄2冊・電子合本・シャドウ・紙版・法廷占拠の旧版）、オフライン起動を確認。バックアップの任意項目も型を検証し、壊れたURLでも表示を復旧します。この安全対策はWebアプリを保護するもので、端末全体のウイルススキャン機能は持ちません。

2026-10-14 v0.8.0確認（Claude）：v0.8.0の12項目、Claude追加7項目、回帰13項目、近刊表紙5項目、v0.7.4の10項目、オフライン2項目、手元のlive_check（CSP・外部スクリプト遮断・ZXing・実NDLおすすめ）がすべて通過。実NDLで新着の詳細・おすすめの詳細・本棚にある本の詳細・ダークモードを375px幅で目視確認。

2026-10-14 v0.11.0：読了本は本棚から外れて記録へ。本棚の詳細にもあらすじを表示し、評価を押しても表紙を保持。読み終えた日はアプリ内カレンダーから選ぶ。本を1回で削除し、6秒間「元に戻す」を表示（同期済みの削除も復旧）。詳細のスクロールは中身だけで行い、閉じるボタンは右上に固定。
